# دليل اختبار BARH على الشبكة الحقيقية

## الملفات المتاحة

### 1. الاختبار الأساسي
```bash
python3 real_network_test.py
```
- اختبار سريع (30 ثانية)
- قياس Ping وإحصائيات النظام الأساسية
- مناسب للاختبار السريع

### 2. الاختبار المتقدم
```bash
python3 advanced_network_test.py
```
- اختبار شامل (60 ثانية)
- اختبار متعدد المضيفين
- قياس عرض النطاق وحل DNS
- تقرير مفصل

### 3. التشغيل السريع
```bash
./run_network_test.sh
```
- يثبت المتطلبات تلقائياً
- يشغل الاختبار الأساسي

## ما يقيسه BARH

### المعايير الأساسية:
- **التأخير (Latency)**: زمن الاستجابة بالميلي ثانية
- **عرض النطاق (Bandwidth)**: سرعة نقل البيانات
- **استخدام المعالج**: نسبة استخدام CPU
- **استخدام الذاكرة**: الذاكرة المستخدمة بالميجابايت
- **عدد الحزم**: الحزم المرسلة عبر الشبكة
- **جودة الاتصال**: معكوس معدل الخطأ
- **معدل الخطأ**: نسبة الأخطاء في الشبكة

### قرارات BARH:
- **no_action**: الشبكة تعمل بكفاءة
- **route_optimization**: تحسين مسارات التوجيه
- **data_compression**: تفعيل ضغط البيانات
- **predictive_prefetch**: تفعيل الجلب التنبؤي

## الملفات المحفوظة

- `barh_test_results_YYYYMMDD_HHMMSS.json`: نتائج الاختبار الأساسي
- `barh_comprehensive_test_YYYYMMDD_HHMMSS.json`: نتائج الاختبار الشامل

## المتطلبات

```bash
pip3 install psutil --user
```

## استكشاف الأخطاء

### إذا كان Ping بطيء (>500ms):
- تحقق من اتصال الإنترنت
- جرب تغيير DNS إلى 8.8.8.8
- أعد تشغيل الراوتر

### إذا فشل الاختبار:
- تأكد من تثبيت Python3
- تأكد من تثبيت psutil
- تحقق من صلاحيات الشبكة
